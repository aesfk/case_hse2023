# Getting More Moscow Residents Into Sport

A team proposal for the November 2023 HSE University case championship. The challenge was to help Moscow residents discover local sports and make it easier for them to take part.

## The proposal

- Promote local sports clubs so residents can find activities near them.
- Organize seasonal events with formats suited to different audiences.
- Design a website for choosing a sport, browsing upcoming events, and organizing a competition.
- Use a volunteer program to help older residents find and join activities.

The team segmented the audience by age and mapped barriers to participation. The presentation connects the proposals to a rollout plan and budget, and pairs a likelihood–impact risk matrix with mitigation measures.
